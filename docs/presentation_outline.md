# 10-minute presentation outline

1. **Problem (1 min)** - why monitoring large social conversations by hand does not scale.
2. **Design (2 min)** - architecture diagram, shared schema, stage-by-stage files.
3. **Walkthrough (3 min)** - live demo: Kibana search, sentiment trend, topic rise, influencer table, alert.
4. **Results (2 min)** - the numbers table from `results.md`, one good and one bad example.
5. **Challenges (1 min)** - API quotas, short noisy text, LIAR domain shift, sparse reply graph.
6. **Next steps (1 min)** - in-domain labels, streaming, alert notifications.

Rehearse with a timer; each section above is one or two slides at most.
